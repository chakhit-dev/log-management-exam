
# วิธีใช้สำหรับทดสอบ

อธิบายไฟล์ต่างๆ และวิธีใช้สำหรับทดสอบ [log-management-exam](https://log.chronotechx.com/)

### ไฟล์

- `postman_collection.json` ใช้สำหรับ import เข้าใน Postman เพื่อทดสอบ api ที่มีให้พร้อม body

- `log_sample.json` ใช้สำหรับเป็นไฟล์ที่จะสามารถอัพโหลด log ไปในเว็บไซต์

- `seed-main.sh` ใช้สำหรับจำลองการยิง logs แบบสุ่มจำนวนมากแบบโดยวันที่จะเป็นวันของเครื่อง

- `seed-revers-date.sh` ใช้สำหรับจำลองการยิง logs แบบสุ่มจำนวนมากแบบโดยวันที่จะเป็นวันของเครื่องย้อนหลัง 7 วัน, 30 วัน

### ใช้งาน

```bash
./seed-main.sh {จำนวนที่ต้องการยิง}
```

```bash
./seed-revers-date.sh {จำนวนที่ต้องการยิง} {30 หรือ 7}
```
